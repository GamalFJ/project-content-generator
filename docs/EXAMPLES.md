# Example docs

## Example use case

```ts
const input = {
  sourceType: "repo",
  source: "https://github.com/your-org/project",
  targetAudience: "developers",
  contentGoal: "Explainer video and architecture walkthrough",
  tone: "technical",
  outputFormats: ["video-script", "tutorial", "storyboard"]
};
```

This generates:
- a technical product summary
- a short architecture explainer
- a step-by-step onboarding flow
- a storyboard for a developer-facing demo
